# 📊 Gold Rate Analytics Dashboard

An interactive Power BI dashboard that analyzes historical gold prices in Indian Rupees (INR) using Python, API integration, and an ETL workflow.

## 📌 Project Overview

The Gold Rate Analytics Dashboard helps users explore historical gold price movements, identify price trends, and understand changes in gold rates over a 30-day period.

Python is used to retrieve and prepare gold-rate data through an API, while Power BI is used to visualize the processed data through interactive dashboards.

## 🎯 Objectives

- Retrieve historical gold-rate data using an API.
- Process and organize data for analysis.
- Analyze gold price movements over time.
- Visualize historical trends using Power BI.
- Present analytical information through an interactive dashboard.

## 🛠️ Technologies Used

- **Python** – Data retrieval and processing
- **MetalpriceAPI** – Gold-rate data source
- **Requests** – API communication
- **ETL** – Extract, Transform, Load workflow
- **Microsoft Power BI** – Dashboard development and visualization

## ⚙️ Project Workflow

1. **Extract:** Retrieve gold-rate data from MetalpriceAPI.
2. **Transform:** Process and organize the API response into a structured dataset.
3. **Load:** Prepare the processed data for analysis in Power BI.
4. **Visualize:** Create an interactive dashboard to explore historical gold prices and trends.

## 📈 Dashboard Features

- Historical gold-rate analysis
- Gold prices displayed in Indian Rupees (INR)
- Daily gold price trend visualization
- Analysis of gold-rate fluctuations over a 30-day period

## 🚀 How to Use

1. Clone or download this repository.
2. Install the required Python dependencies, if Python scripts are included.
3. Configure your MetalpriceAPI credentials securely.
4. Run the data retrieval and processing workflow.
5. Open the Power BI report in Microsoft Power BI Desktop.
6. Configure the data source and refresh the report as required.

## 🔐 API Configuration

An API key may be required to retrieve data from MetalpriceAPI.

Store your API key securely in an environment variable or a local configuration file that is excluded from version control. Never publish private API credentials in the repository.
